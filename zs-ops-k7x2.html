Monthly Care Plan SOP

What you do every month for Basic and Pro clients

▶
Block 2–3 hours on the first of every month and run through every Care client in a row. Basic clients take about 10 minutes each. Pro clients take 30–45 minutes each.

Every month

Care Basic

$79/mo · ~10 min per client

  • Confirm hosting is active and site is live
  • Check uptime monitor — no outages this month
  • Confirm daily backups are running
  • Apply any pending security or plugin updates
  • Check site load speed — flag if over 3 seconds
  • Send brief check-in: "All good this month — site is running great."

Every month

Care Pro

$149/mo · ~45 min per client

  • Everything in Care Basic
  • Check keyword rankings — note any movement up or down
  • Write and publish monthly Google Business post
  • Apply any edit requests from the client (up to 2hrs)
  • Pull traffic and performance data from analytics
  • Write monthly report: rankings, speed, traffic, uptime, edits done
  • Email report to client using the monthly check-in template
  • Note remaining edit time for the month
Care plan reminders to set in your calendar
