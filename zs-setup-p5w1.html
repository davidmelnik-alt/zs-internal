GitHub — Website code backup

Free forever, never lose your site code

▶
You don't need to know how to code to use GitHub. Just drag and drop your files into the repo from the browser. It auto-saves every version.
  • ✓

    Create your GitHub account

    github.com — Sign up free
  • ✓

    Create repo: zadanstudio-website

    Set to Private. Add a README. This holds all your site code.

    github.com/new — Create repo
  • ✓

    Upload your site files

    index.html, portfolio.html, about.html, contact.html, style.css, assets/ folder. Drag and drop directly in the browser — no terminal needed.

    Go to your repo → Add file → Upload

Docuseal — E-signature contracts

Free, takes 10 minutes to set up your first template

▶
Docuseal is free for up to 10 documents/month — plenty for now. You'll build one contract template and reuse it for every client.
  • ✓

    Create your Docuseal account

    docuseal.com — Sign up free
  • ✓

    Create your contract template

    New template → upload a PDF or use their editor. Include: project scope, price, payment terms (50/50), timeline, revision policy, ownership of files on final payment.

    New template in Docuseal
  • ✓

    Add signature + date fields

    Drag a Signature field and a Date field to the bottom of the contract. Add fields for: Client Name, Business Name, Package, Total Price so you can fill them in per client.

    Your templates
  • ✓

    Test it — send yourself a copy to sign

    Send the template to your own email, sign it, confirm it works. Then save the template link in Notion → Operations → Contracts.

    Docuseal dashboard Save link in Notion
  • ✓

    How to use it for each client

    Dashboard → Use template → fill in their name + package → enter their email → Send. They get a link, sign on their phone or laptop, you get notified, both get a PDF copy automatically.

    Docuseal dashboard
